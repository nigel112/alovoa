# BaeLink mobile assets

Branded artwork for the mobile app, generated by `scripts/brand/build-assets.mjs`
from the same vector masters as the web icons - so the app and the site always
share one identity.

**An APK cannot be built from this repository.** This repo is the Spring Boot
back end; the app is the separate Expo project
[Alovoa/alovoa-expo](https://github.com/Alovoa/alovoa-expo). Building Android
binaries also needs a JDK 17, the Android SDK and Gradle, none of which exist in
this sandbox (and `dl.google.com`, `repo1.maven.org` and
`services.gradle.org` are unreachable from it). Use Expo's **EAS Build**, which
compiles in the cloud - no local Android toolchain required.

## 1. Copy the artwork

Clone the app and drop in the `expo/` files (filenames match what
`app.config.js` already expects):

```sh
git clone https://github.com/Alovoa/alovoa-expo.git
cd alovoa-expo
cp /path/to/alovoa/docs/mobile-assets/expo/*.png assets/
```

| file                 | becomes                | notes                                                    |
| -------------------- | ---------------------- | -------------------------------------------------------- |
| `icon.png`           | `assets/icon.png`      | 1024², full-bleed rose tile with a white mark            |
| `icon-round.png`     | `assets/icon-round.png`| 1024², same badge inside a circle (Android round icon)   |
| `adaptive-icon.png`  | `assets/adaptive-icon.png` | 1024², white silhouette inside Android's safe zone   |
| `monochrome-icon.png`| `assets/monochrome-icon.png` | 1024², white silhouette (Android themed icons)    |
| `splash.png`         | `assets/splash.png`    | 3000×1646, white lockup for the **light** splash         |
| `splash-dark.png`    | `assets/splash-dark.png` | 3000×1646, white + rose lockup for the **dark** splash |
| `favicon.png`        | `assets/favicon.png`   | 48², web favicon                                         |

For a bare React Native project (no Expo) use `android/res/mipmap-*/ic_launcher.png`,
`ios/AppIcon-1024.png`, `notification-icon.png` (flat white silhouette, as
Android requires) and `play-store-icon.png` instead.

## 2. Point the app at BaeLink (`app.config.js`)

```js
"name": "BaeLink",
"slug": "baelink-expo",
"scheme": "baelink",
"splash": {
  "image": "./assets/splash.png",
  "resizeMode": "contain",
  "backgroundColor": "#FF3D68",
  "dark": { "image": "./assets/splash-dark.png", "backgroundColor": "#12121A" }
},
"ios": {
  "bundleIdentifier": "com.baelink.expo",
  "associatedDomains": ["applinks:your-domain.com"],
  "infoPlist": { "LSApplicationQueriesSchemes": ["baelink"] }
},
"android": {
  "adaptiveIcon": { "backgroundColor": "#FF3D68" },
  "intentFilters": [{ "action": "VIEW", "data": [{ "scheme": "baelink" }],
                      "category": ["BROWSABLE", "DEFAULT"] }],
  "package": "com.baelink.expo"
}
```

Also update:

- `URL.tsx` - `export const DOMAIN` must point at your BaeLink server. For a
  local back end use `http://localhost:8080` (iOS simulator) or
  `http://10.0.2.2:8080` (Android emulator); the file already has commented
  examples.
- `screens/Login.tsx` (~line 183) - the string `Alovoa` shown under the logo.
- `updates.url` - the GitHub releases URL, or leave `EAS_PROJECT_ID` set and let
  EAS fill it in.

> Changing `android.package` / `ios.bundleIdentifier` means a **new** listing in
> Play Console and App Store Connect. Decide the identifiers before the first
> release build.

## 3. Build the APK (cloud)

```sh
npm i -g eas-cli
cd alovoa-expo
eas login                 # free Expo account
eas build:configure       # links the project, sets EAS_PROJECT_ID
```

Ask EAS for an APK rather than an app bundle by adding one line to the
`preview` profile in `eas.json`:

```json
"preview": {
  "distribution": "internal",
  "channel": "preview",
  "android": { "buildType": "apk" }
}
```

Then:

```sh
eas build -p android --profile preview
```

The build runs on Expo's servers (roughly 10-20 minutes) and finishes with a
download link for the APK. Install it with `adb install app.apk` or by opening
the file on the device.

To build on your own machine instead you need JDK 17 and the Android SDK
(`ANDROID_HOME`), then `npx expo prebuild && cd android && ./gradlew assembleRelease`.

## Palette

| token    | hex       | used for                                  |
| -------- | --------- | ----------------------------------------- |
| rose     | `#FF3D68` | primary, icon tile, splash background     |
